# docs/research moved to docs/evidence

The research documents that lived here moved, unchanged and with their git history, to [docs/evidence/](../evidence/INDEX.md) on 21 Oct 2026 (motion-pack v0.5, the playbook).

Every learning in them is now an atomic, graded rule in [playbook/rules/](../../playbook/rules) and is bundled into ready skeletons in [playbook/formats/](../../playbook/formats). Read the playbook first; open a document in docs/evidence only for the full reasoning behind a rule, through the `sources` of the rule.

An old link `docs/research/<file>.md` resolves at `docs/evidence/<file>.md`: same file name, same content.
