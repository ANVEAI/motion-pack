### How each part follows its spec

- **`ui.glassPanel`**: a `foreignObject` div with CSS `backdrop-filter: blur() saturate()` (mode `backdrop`), or an SVG copy of the backdrop blurred by `feGaussianBlur` (mode `plate`: an image or a gradient). The blur radius, tint alpha, edge alpha and grain are the closed-form `glassState(p, u)`; `blurIn: [t0, t1]` resolves the glass; the exit takes blur and tint to 0 instead of using a group opacity (an ancestor with opacity < 1 stops `backdrop-filter` seeing the page; a test pins that). The noise is `feTurbulence` seeded by `floor(t * grainFps)`.
  - **Measured in real Chrome** (`type/tests/r78-sheet.mjs`): sharp steps in the panel drop from 13.8 to 0 per 1000 px in both modes, and the two modes differ by 2.7 / 255 on the same gradient.
  - **Measured in the HyperFrames capture** (`templates/demo-r78`, HyperFrames 0.8.142, Chrome headless shell 152, "drawelement capture, hardware gpu"): the backdrop blur survives into the MP4 (frames in `out/sheet.jpg`).
- **`ui.rimLight`**: head angle = `turns * 2 pi * ease((t - t0) / (t1 - t0))` from the chosen corner (`rimState`); intensity read from each run's polar angle about the centre (a conic gradient built from path runs, so it also works in a canvas or a static SVG); one stroke width in px at every t (tested as a set of widths); `rimContrast(p)` is the WCAG ratio of the hot core on the field (14.2 by default; test needs >= 4.5).
- **`background.skyClouds`**: periodic fbm (hashed integer lattice, period in cells), two parallax layers, drift `drift * t`; loop L = a whole number of periods per L (frame t and t + L identical in node, and in Chrome pixels), band limit by dropping the octave whose wavelength is under 3 samples, `cover` -1 = the preset's. `dunes`: 3-6 clipped asymmetric ridges, light and shade faces from the sun side, haze on the far ones.
- **`ui.reviewLayer`**: flags follow `track` (composition seconds), pins pop on `at`, record clock `floor(clamp(u - at, 0, dur))`, slider card with a face handle; names fictional and the `note` "placeholder names and comments" is on while anything is.
- **`ui.approvalSlider`**: `approvalState(p, u)` is the state machine; `approvalTimes(p).approvedAt` is the flip frame; the cue sheet puts `sfx/ui/success_chime` (an existing sound) on it and `sfx/ui/drag_lift` on the grab; the markup carries `data-state`.
- **`type.sentenceAcrossShots`**: the word changes on exactly the cut frame (tested one tick either side) and sits in a fixed slot; `carry` lays the whole sentence out once; `sentenceLint` flags short shots.
- **abReplay** (`cutgen.py ab-replay`): modes `replay` (the clip twice, flip = first frame of pass B, both passes read the same `src_in`) and `flip` (one shot, flip at 42 % by default). Switch frame = flip frame, `switch_sample` = round(flip * 48000 / fps), hard switch by default; the gain on stem B = LUFS(A) - LUFS(B), clamped to +-12 dB; `plan_audio` is what `ears` reads; `checks` re-derive every rule (9 hand edits each fail the right check). `verify-picture` compares pass A with pass B of a rendered file by ffmpeg psnr (a bit-equal FFV1 concat reads identical; a different second pass reads under 30 dB).
  - **`ears/checks_ab.py`** (`ears/ab_replay`, only with `plan.audio.abReplay`): level match by integrated LUFS (<= 1 dB pass, <= 2 dB warn, more fail) and the swap ON the flip frame by a change-point detector on 12 log-spaced bands (100 ms before against 100 ms after each boundary): localises a hard switch to about 5 ms (a 1-frame shift reads 1.0 +- 0.3 frames; 3 and 6 frames fail).
- **`layout.textWall` / `layout.pillWall` / `device.lockScreen`**: see the module README. The wall is endless (rows numbered by absolute card, seeded by it), the pill wall's lit pill is the measured text width plus padding at every settled step, the lock screen's clock is a parameter and the source reads no clock (a test greps it, and `tools/tests/test_no_clock.py` covers the module).

## What is weaker than I would like

- **`ui.rimLight` is a path-run conic, not a GPU one.** It is exact and works everywhere, but the bloom is one blurred copy of the head runs; a plate-sized colour bleed is a radial gradient, not a real light transport. It reads well on a dark field; on a bright plate the rim barely shows (the sheet puts it on dark).
- **`ui.glassPanel` backdrop mode is a DOM-only part.** In a canvas export or a still SVG it draws a tinted rectangle with no blur; use `mode: 'plate'` there. The default (`auto`) picks `backdrop` when no `plate` is given.
- **The `ears/ab_replay` flip detector needs a real spectral difference between the stems.** Identical stems, or stems that differ only below 150 Hz or above 8 kHz, report "no clear change"; stationary-noise stems give a prominence of about 3.2-4.1 (threshold 2.5, tunable in `ears/manifest.json`). Real dialogue over a changed bed is untested: first use on a real file should be listened to.
- **`layout.pillWall` scripts.** The bundled font has Latin, Greek, Cyrillic and Vietnamese only; a wall "in many scripts" beyond those needs a fetched font (outside this pack's owned-fonts rule), so the part lints and does not pretend.
- **`layout.textWall` text is lorem in monospace** (so the characters per line are exact in every renderer). It reads as a wall of text, not as a particular product's answer.
- **`verify-picture` on a delivered file** with different overlay text in the two passes needs `--crop` of a region without overlays, or the plate render.
- **Sound for the new parts is existing sounds only** (no new sounds were synthesised): `sfx/ui/*`, `sfx/hw/light_sweep`, `sfx/tx/cut_tick`, `sfx/device/*`.
- Not run: the browser suites that need a GPU beyond this lane's (`layers/tests/layers.test.mjs`, `type/tests/type.test.mjs` ...), `bash terminal/tests/smoke.sh`, Blender.
