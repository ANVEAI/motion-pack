# 3D: three.js plates, post effects, React Three Fiber, Drei, physics

These results were measured on 13 Oct 2026 on a real production set: 18 s, 1080x1920, a 4-subframe supersampled three.js studio with its own post chain. Hardware: Apple M3 Pro, Chrome 154, ANGLE Metal.

All variants passed the seek gates unless stated. The question was look, cost and complexity.

## Verdicts

| question | answer |
|---|---|
| Replace a hand-tuned post chain with pmndrs `postprocessing`? | **No.** It matched the look only after two custom effects and per-camera re-tuning, and cost 20–37% more per frame. Its DoF also thinned in-focus dark text. |
| three's own `examples/jsm/postprocessing` (EffectComposer, BokehPass, UnrealBloomPass)? | **No.** About 55% more per frame; BokehPass re-renders the scene for depth and haloes near-field silhouettes. |
| SMAA (+ MSAA 4) instead of jittered supersampling? | **Only for previews.** Edges come out clean and it is about 3x cheaper. But a single sample loses the soft shadow (the light jitters per subframe) and the 180° shutter blur. |
| Any place for pmndrs `postprocessing`? | **Yes, as a single tail `EffectPass`** for a LUT grade or one extra effect, after your comp and before accumulation. 16 lines; bit-identical when idle; seek-safe. |
| Upgrade three r160 → r186 mid-series? | **No.** Every lit surface rendered about 7/255 darker (32.8 dB vs the old look), a custom shadow-chunk patch silently stopped applying, and pmndrs 6.39 changed its DoF units under the same property names. Pin three per project and upgrade only between projects, with a re-grade. |
| React Three Fiber + Drei + `@react-three/postprocessing` for offline plates? | **No.** Pixel-identical output (103.8–106.5 dB) and the same GPU time as vanilla, at 215 MB vs 35 MB installed, plus a bundler and 2.4x the code. |
| Drei? | **Port two pieces to vanilla:** `SoftShadows` (PCSS) and `MeshReflectorMaterial`. Skip `Float`, `Sparkles`, `AccumulativeShadows` and `MeshTransmissionMaterial` for seeked renders: they failed G3 or use randomness or the clock at mount. |
| Physics? | **Bake it with Rapier at build time** and play the table back. Live `@react-three/rapier` failed G2 (13.6 dB). |

**Recommended stack for frame-exact 3D plates:**
- three (pin one version for the whole project) with your own supersampled post chain, or the pack's kit;
- optional `postprocessing@6.36.7` (Zlib) as a tail stage;
- `@dimforge/rapier3d-compat@0.21.0` (Apache-2.0) at build time only.

## Make any WebGL page testable

```js
window.__seek = (t) => window.renderAt(t);    // or the production path: (t) => window.renderFrame(Math.round(t * fps))
```

If the page runs its own `requestAnimationFrame` preview, stop it in test mode (`?norun=1`). Otherwise the loop repaints between the seek and the capture, and the gates fail at 8–23 dB.

## The pmndrs tail stage (seek-safe pattern)

```js
import { EffectPass, LUT3DEffect, LUTCubeLoader } from 'postprocessing';     // import map → postprocessing@6.36.7/build/index.js
const lut  = new LUTCubeLoader().parse(await (await fetch('./grades/look.cube')).text());
const tail = new EffectPass(camera, new LUT3DEffect(lut, { tetrahedralInterpolation: true }));
tail.initialize(renderer, false, THREE.HalfFloatType); tail.setSize(W, H);
const tailRT = new THREE.WebGLRenderTarget(W, H, rtOpts);
// per sample, after your comp pass:
tail.fullscreenMaterial.time = t;                 // time comes from t, never from a clock
tail.render(renderer, compRT, tailRT, 0, false);  // deltaTime 0
// then accumulate from tailRT instead of compRT
```

**Why `0` and `time = t`:**
- `composer.render()` with no argument advances a wall-clock Timer, and `EffectPass` adds `deltaTime` into `time`.
- With library defaults, `NoiseEffect` failed all three gates (50.6 and 54.3 dB).
- Driven from `t`, it passed.

**pmndrs traps:**
- Camera near/far are copied only at pass creation or `setMainCamera()`. Call it again when the camera changes.
- `SelectiveBloomEffect` masks by depth equality, so it blooms whatever sits under a selected plane. It has no emitter exclusion.
- `SMAAEffect` loads lookup images asynchronously. Await its `load` event before `__ready`.
- `ToneMappingMode.NEUTRAL` needs three r162+. Adaptive tone mapping keeps luminance history, so it is not seek-safe.
- `npm i postprocessing` pulls a second three through peers. Use `--legacy-peer-deps` or an import map.

**three addons traps:**
- Pass `0` to `EffectComposer.render()`.
- `OutputPass` encodes sRGB again if your final pass already does.
- `BokehPass` sets a white clear colour and `autoClear = false`.

## React Three Fiber, if a React page must be seeked

Use:
- `frameloop="never"`;
- a store-driven `t`;
- `advance(0)` after setting state. Never `advance(t)`: the delta becomes t minus the previous seek;
- `dpr={1}`;
- explicit sizes and `preserveDrawingBuffer`;
- a gate that sets `__ready` only after the composer is built.

The wrappers change defaults:
- `<EffectComposer>` defaults to MSAA 8 and forces NoToneMapping;
- `<SelectiveBloom>` hard-codes ADD;
- `<DepthOfField>` sets `MULTIPLY_RGB_SET_ALPHA`;
- DoF placed after bloom erases the bloom.

## Baked physics with Rapier

**Bake (build time, Node):**
- Simulate at a fixed 1/60 s step with engine substeps (6 were needed for thin cards), from a seeded scene spec.
- Write a JSON table of per-frame position and quaternion for every body.
- Cost: a 4 s, 25-body scene baked in about 0.13–0.25 s to a 387 KB table (97 KB gzipped).

**Proven deterministic:**
- 8 CLI bakes on Node 21, 22 and 25, plus 3 bakes in Chrome 154, produced one SHA-256.
- Cross-CPU identity was not tested. For that, Rapier publishes `rapier3d-deterministic-compat`.

**Play back (render time, browser):** a 63-line `table-player.js` with no dependencies.
- `apply(t, meshes)` lerps positions and slerps rotations between steps.
- `firstContact(body)` and `motion(t)` let the timeline add a desk bob on impact or extra motion-blur subframes on fast frames.
- On the real set it passed G1–G4 with no mismatching pixel.

**What to avoid:**
- `@react-three/rapier` steps live inside an accumulator: G2 fails, and at its default step the scene broke on impact.
- It also pins an older Rapier (0.19.2) on which the box toppled instead of landing flat. The seekable remount-and-replay variant works, but needs 114 MB of tooling and a bundler to do what the table does.
- Keep springs or closed-form curves for single-object moves. Bake only multi-body motion: scatter, piles, topples, drops.

**Sound from physics:** contact events in the table can drive SFX cues on frame F+1 (scatter clicks, impact thuds).
