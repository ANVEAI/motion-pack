# media

The film and the promo were made with this pack (HyperFrames compositions, the pack's transitions, type, layers, three.js objects, Blender plates, music and sound effects).

| file | what |
|---|---|
| `film.mp4` | the showcase film (README "More films"): 46 s, 1920x1080, −14.1 LUFS. An agent made every frame: Blender plates, GL transitions, kinetic type, a three.js catalog fly-through, the lab scoreboard and synthesised music and sound |
| `promo.gif` | an 8 s loop of the promo, 800x450, shown in the README under the showcase film |
| `promo.mp4` | the first promo: 42 s, 1920x1080, −14 LUFS |
| `promo-9x16.mp4` | the same promo re-laid out for 9:16 (Shorts, Reels) |
| `poster.png` | the promo's poster frame, 1280x720 |
| `styles/<id>.mp4`, `styles/<id>.jpg` | each style's 10 s demo (960x540 preview, under 2 MB) and its poster; the full 1080p demos are release assets |
| `styles/mosaic.gif` | the README hero: the style demos playing at once (under 3 MB) |
| `films/<format>.mp4`, `.gif` | 640-wide previews and 4 s loops of the v0.5 proof runs (launch film, proof clip, explainer; placeholder brands, example data) |

The README plays the film through a GitHub attachment URL, because GitHub only shows inline video players for uploaded attachments, not for files in the repository.
