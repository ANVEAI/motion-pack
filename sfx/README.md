# motion-pack / sfx : the synthesised sound library (owned, reusable)

356 sounds in 28 families, all generated by code (numpy / scipy / numba): no samples, no downloads, no speech, no paid generation. 48 kHz, 24-bit WAV, stereo, peak-normalised to -6 dBFS, trimmed, edge-faded. `manifest.json` has id, category, tags, duration, anchor, peak, true peak, LUFS (integrated / momentary max / short-term max), spectral centroid, crest, suggested over-bed level, pairing transitions, roles, phone-safety and a SHA of the deterministic render for every sound. Ideas reused (re-written, not vendored): ANVE's v9 launch-film SFX script (TPT filter, sin^2 attack envelopes, equal-power pan, IR), `mix9.py` (hit contract, over-bed solver, limiter), `spec-to-loop/scripts/measure_audio.py` (BS.1770 meter).

## Build, test, listen-free QA
```bash
cd sfx
python3 build_library.py            # renders library/<family>/<id>.wav + manifest.json (about 10 s)
python3 qa.py                       # determinism, finite, peak, DC, start/end edges, sub energy, centroid per family, seed variation, loop seams, python-vs-ffmpeg ebur128
python3 tests/test_primitives.py    # svf -3 dB, noise colours, Karplus-Strong pitch, BS.1770 vs ffmpeg, limiter ceiling, anchor contract (F+1 frames)
python3 demo/demo_sfx_reel.py       # 20 s reel, one cue per family, mastered -14 LUFS / <= -1.5 dBTP -> demo/out/sfx_reel.wav
python3 demo/contact_sheet.py       # spectrogram contact sheets -> demo/stills/*.jpg (visual check of sweeps, envelopes, bandwidth)
python3 make_readme.py              # regenerates this file from the measured manifest
python3 tools/listening_checklist.py # writes LISTENING_PASS.md: the by-ear checklist (nothing has been auditioned yet)
python3 tools/check_origin.py DIR    # provenance gate for any IMPORTED audio: ORIGIN.txt (url, author, licence, snapshot, date, zip sha) + licence allow-list; exit 2 = refused
python3 tools/catalog_import.py DIR --category NAME [--dry]   # normalise approved external WAVs (48k/24-bit, -6 dBFS) + same measurements, tagged source:ext, into library_ext/ (never manifest.json)
```

QA status at build: **356 sounds, 0 fails, 15 warnings**; cross-meter max |python - ffmpeg ebur128| on every sound of 1.5 s or more = 0.05 LU (limit 0.1).

## The contract (so every motion component can attach sound)
- **Anchor.** Each sound has `anchor_sample` (also `anchor_ms`): the designated peak / impact. A cue whose VISUAL frame is F puts the anchor on sample **(F + 1) x 48000 / fps** (one frame after the picture, the v9 rule). Risers end one frame BEFORE the hit anchor (`anchor_frame_offset = -1`).
- **Determinism.** `render(id, seed)` is a pure function; the same code and seed give identical bytes (`sha` in the manifest). The mixer uses seed + occurrence index for round-robin variants.
- **Level.** Library level is -6 dBFS peak (headroom for layering). Real levels are solved by `music/mixer.py` against the bed: hero +4.5, whoosh +2, ui +4, logo +5 dB (K-weighted, 60 ms); `over_bed_db` in the manifest is the default.
- **Phone check.** `phone_safe=false` (voiced level drops > 6 dB on a phone speaker) means a sub-heavy sound: pair it with a mid-range cue (mixer lint R12).
- **Use from Python.**
```python
import sys; sys.path.insert(0, 'music'); import mixer
m = mixer.Mix(fps=30, length_s=12); m.add_bed(bed_audio)           # bed: float (n,2) at 48 kHz
m.add_cue('snd.hit.thud', frame=60)                                  # anchor lands on sample 61 x 1600
m.add_transition('whip', frame=120, duration_frames=8, energy=0.6)  # sweetener table -> cues
rep = m.render('out_dir')                                           # master.wav -14 LUFS / -1.5 dBTP, stems, report with measured over-bed per cue
```
- **Bundles**: `bundles.json` (from `bundles.py`) maps cue ROLES to ids per video type: launch_film, mime_spot, beat_edit, talking_head, short_film, product_ad, kinetic_type, loop_short, india_festive, voice_agent_demo, office_comedy, saas_launch, mockumentary, archive_open, neon_power_on, trailer, saas_ui, hardware_launch (plus bed presets, BPM range, level notes). Ids are validated against the manifest.
- **Loops under a state**: a loop cue runs to the end of the mix unless it gets `until_frame` (`Mix.add_cue(sid, frame, until_frame=F)`, or `"until_frame"` in a cue sheet): e.g. `snd.ui.agent_working` under one "AI at work" state, stopped with a 40 ms fade on the result frame.
- **Transition sweeteners**: `mpaudio/sweeteners.py` -> `sweeteners.json` (kind -> sound, anchor position, tier, over-bed). Transition kinds: blurCross, dip, dipToBlack, dissolve, ditherDissolve, filmBurn, flash, freezeHold, glitch, hardCut, ink, iris, jcut, lightLeak, lumaWipe, maskReveal, match, morph, pagePeel, pixelSort, push, scalePunch, shutter, smash, speedRamp, spin, swipeUp, whip, zoomThrough.
  The 5 formerly pending pairings (shutter, swipeUp, spin, pagePeel, pixelSort) and dip are explicit rows; a kind with no row (new visual transitions) falls back to its `transitions/catalog.json` sfx list (`source: transitions/catalog.json` in sweeteners.json; loops are never used as sweeteners).
- **Round robin**: ids tagged `rr:4` (foley, tabla, keyboard, mouse...) have four useful takes: seeds s..s+3. The mixer already uses seed + occurrence for a repeated id.

## Tags
`family:*`, `size:{xs,s,m,l,xl}`, `tier:{1,2,3}`, `anchor:{crest,noise,scatter,end,start,loop}`, `tonal:{yes,no}`, `key:A`, `mood:*`, plus modifiers (`sub`, `reverse-swell`, `wordless`, `foley`, `loop`...). `manifest.json` -> `by_tag` and `by_transition` are ready-made indexes.

## Honest limits
- **Nothing here was auditioned by a human yet.** Defaults are starting values from DSP practice; the QA is measurement (spectra, loudness, edges, determinism) plus spectrogram stills. Do one listening pass per new family before shipping a film; record one line per family here.
- Glass / bell / metal / bubble / formant numbers come from textbook or remembered tables (docs/evidence/sound.md grades C): they may need retuning by ear. The word-free voices are formant-synth stylisations, not real voices.
- Platform loudness: only Spotify (-14 LUFS, -1 dBTP) and YouTube normalisation behaviour are documented; Instagram / TikTok / X / LinkedIn are D-grade: house master is -14 LUFS-I / <= -1.5 dBTP (AAC probes <= -1.0) and still needs the empirical upload test (docs/evidence/sound.md 5.3).
- 2026-10-13 expansion (+100 sounds: indian 26, foley 20, device 16, ui +5 voice-assistant, impacts +6, risers +5, whooshes +4, ambience +11, crowd 3, cartoon +4) is equally unheard: see `LISTENING_PASS.md`. Indian voices are stylised synthesis (no samples, no imitation of recordings); crowd sounds are word-free formant voices.
- Spectral-centroid ranges and sub-energy limits in `qa.py` are sanity guards (warn), not perceptual claims.
